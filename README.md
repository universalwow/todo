# UNI-7

## Overview

This repository contains a small web app for Linear ticket `UNI-7` (新增todo列表).

## Development

- Install dependencies:

```bash
cd web
npm install
```

- Start dev server:

```bash
cd web
npm run dev
```

- Lint / test / build:

```bash
cd web
npm run lint
npm run test
npm run build
```
